Connect your TV

  1. On the TV: Settings → System → About. Click Android TV OS build 7 times.
  2. Settings → System → Developer options → turn on Network debugging (or USB debugging).
  3. Find the TV's IP in Settings → Network & Internet → your Wi‑Fi.

When the TV asks “Allow network debugging?”, choose Always allow.
