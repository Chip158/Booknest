# Midnight Archive app

The Archive in your pocket. Expo (React Native + TypeScript) with Expo Router.
See ../CLAUDE.md for the full build brief and milestones.

## Run it on your phone

1. Install **Expo Go** from the App Store or Google Play.
2. In this folder: `npm install`, then `npx expo start` (add `--tunnel` if your phone is not on the same Wi-Fi).
3. Scan the QR code. iPhone: use the Camera app. Android: use the scanner in Expo Go.

## Checks

```bash
npx tsc --noEmit   # type check
npx expo lint      # lint
npx expo-doctor    # dependency health
```
